# Ruta de aprendizaje en análisis de datos

Este repositorio documenta mi proceso de formación para avanzar hacia un puesto de analista de datos junior.

## Sobre mí

Soy técnico en Análisis y Programación de Software, con experiencia en soporte de TI y servicio al cliente.

## Objetivo

Desarrollar las habilidades necesarias para limpiar, analizar y visualizar datos, y comunicar hallazgos útiles para la toma de decisiones.

## Contenido de la ruta

- `00_preparacion`: objetivo profesional y análisis de ofertas laborales.
- `01_sql`: consultas y ejercicios de SQL.
- `02_excel`: fórmulas, análisis y tablas dinámicas.
- `03_power_bi`: modelos de datos, DAX y dashboards.
- `04_python`: análisis de datos con Python y Pandas.
- `05_ia`: inteligencia artificial aplicada al análisis de datos.
- `06_proyecto_colombia`: proyecto con datos abiertos de Colombia.
